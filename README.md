# Projeto-IP: Find AI at CIN
  
<div>
  <h3> Como funciona o jogo? </h3>
  <h5> No jogo "Find AI at CIN" seu objetivo principal é procurar as IA's dentro do Centro de Informática (CIN) para conseguir passar na cadeira de IP. Porém, existem diversos obstáculos (monitores) que vão atrapalhar sua busca. Caso você não encontre todas as IA's, alguns professores irão
  lhe reprovar e você terá que repetir tudo do começo... </h5>
